# Assignment 3 – Simulations

This folder contains the Python simulation script for Mobile Computing Assignment 3.

`run_assignment3_simulations.py`

- Q1 – Wireless Mobility and Handoff

## Execution

```bash
cd ~/Desktop/MobileComputing-Execution/Assignment-3
python3 simulations/run_assignment3_simulations.py
```
